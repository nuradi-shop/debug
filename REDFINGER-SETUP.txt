BROCK STORE - SETUP REDFINGER
==============================

Sistem memakai MongoDB URL/database yang SAMA dengan website sekarang.
Tidak perlu membuat MONGODB_URL baru.

Collection yang dipakai:
1. redfinger_products
2. redfinger_stock

A. PRODUK
---------
Saat halaman Code REDFINGER pertama kali dibuka, sistem otomatis membuat 2 produk jika belum ada:

- redfinger-vip-7d  | REDFINGER VIP 7 HARI  | Rp21.000
- redfinger-vip-30d | REDFINGER VIP 30 HARI | Rp55.000

Harga/nama/durasi bisa diedit langsung di collection redfinger_products.
JANGAN sering mengganti productId karena dipakai untuk menghubungkan stok.

B. CARA TAMBAH STOK
-------------------
Buka MongoDB Atlas -> database Cluster0 -> collection redfinger_stock.
Masukkan SATU dokumen untuk SETIAP redeem code.

Contoh VIP 7 Hari:
{
  "productId": "redfinger-vip-7d",
  "code": "ISI-CODE-REDFINGER-DISINI",
  "status": "available"
}

Contoh VIP 30 Hari:
{
  "productId": "redfinger-vip-30d",
  "code": "ISI-CODE-REDFINGER-DISINI",
  "status": "available"
}

Kalau ada 5 code, masukkan 5 dokumen.
Website menghitung dokumen dengan status "available" sebagai stok.

Setelah pembayaran sukses, 1 code akan otomatis berubah menjadi:
{
  "productId": "redfinger-vip-7d",
  "code": "...",
  "status": "sold",
  "transactionId": "...",
  "soldTo": "email pembeli",
  "phone": "nomor WA pembeli",
  "soldAt": "..."
}

C. ALUR REDFINGER
-----------------
Code REDFINGER -> Nomor WA + Email -> pilih VIP 7H/30H -> QRIS Sakurupiah -> pembayaran berhasil -> ambil 1 code MongoDB secara atomic -> status code SOLD -> tampil di invoice -> kirim email khusus REDFINGER -> kirim notif Telegram admin.

D. ENV VERCEL
-------------
Gunakan env yang sekarang. Pastikan juga ada:
TELEGRAM_BOT_TOKEN
TELEGRAM_OWNER_ID

Jangan simpan token/password/API key langsung di GitHub.
