PANDUAN LENGKAP SETUP MONGODB ATLAS
BROCK STORE – REDFINGER

A. MEMBUAT PROJECT
1. Buka MongoDB Atlas lalu login.
2. Buat project baru, misalnya: panelbrockstore.
3. Masuk ke project tersebut.

B. MEMBUAT CLUSTER
1. Buka Database / Database Deployments.
2. Klik Create / Build a Database.
3. Pilih cluster gratis jika tersedia.
4. Gunakan nama cluster: Cluster0.
5. Tunggu sampai cluster selesai dibuat.

C. MEMBUAT DATABASE USER
1. Buka Database Access.
2. Klik Add New Database User.
3. Buat username dan password khusus MongoDB.
4. Simpan username dan password tersebut.
5. Berikan hak akses Read and Write yang diperlukan.

D. NETWORK ACCESS
1. Buka Network Access.
2. Klik Add IP Address.
3. Masukkan: 0.0.0.0/0
4. Simpan.
Pengaturan ini diperlukan agar aplikasi Vercel bisa mengakses MongoDB Atlas.

E. MENGAMBIL CONNECTION STRING
1. Kembali ke Cluster0.
2. Klik Connect.
3. Pilih Drivers.
4. Pilih Node.js.
5. Copy connection string.
Contoh:
mongodb+srv://USERNAME:PASSWORD@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
6. Ganti USERNAME dan PASSWORD dengan Database User yang sudah dibuat.
7. Jangan simpan connection string di GitHub.

F. MASUKKAN MONGODB_URL KE VERCEL
1. Buka Vercel.
2. Pilih project BROCK STORE.
3. Settings → Environment Variables.
4. Tambahkan:
Name: MONGODB_URL
Value: connection string MongoDB Atlas.
5. Simpan.
6. Redeploy project.

G. MEMBUAT DATABASE DAN COLLECTION
1. MongoDB Atlas → Cluster0 → Browse Collections.
2. Klik Create Database jika database toko belum ada.
3. Isi:
Database Name: Cluster0
Collection Name: redfinger_products
4. Time Series: OFF.

M. SATU KODE = SATU DOKUMEN
Setiap redeem code harus dibuat sebagai dokumen terpisah.
Jika punya 10 kode, buat 10 dokumen terpisah.

N. CARA WEBSITE MEMBACA STOK
Website menghitung dokumen dengan:
"status": "available"

Jika ada 3 dokumen available → Stok 3.
Jika ada 1 → Stok 1.
Jika tidak ada → STOK HABIS dan produk tidak bisa dipilih.

O. SETELAH KODE TERJUAL
Dokumen tidak perlu dihapus.

Sebelum terjual:
{
  "productId": "redfinger-vip-7d",
  "code": "RF7D-ABCD-1234",
  "status": "available"
}

Setelah transaksi berhasil, seharusnya menjadi kurang lebih:
{
  "productId": "redfinger-vip-7d",
  "code": "RF7D-ABCD-1234",
  "status": "sold",
  "transactionId": "ID-TRANSAKSI",
  "email": "email-pembeli@gmail.com",
  "soldAt": "tanggal-dan-waktu"
}

available = masih bisa dijual
sold = sudah terjual
